Changelog

Everything we've shipped.

Every shipped update to Roota, in one place — from the first CLI prototype to the engineering ops dashboard.

v0.4.0July 2026Latest
  • Added Full Overview dashboard — upload or paste logs, pick a repo, and get an AI diagnosis with line, error, and warning counts.
  • Added Incidents view with the complete history of every analysis and inline "Correct / Incorrect" feedback.
  • Added Logs explorer to inspect the raw input and parsed entries behind any past incident.
  • Added Profile tab — see your name, email, member-since date, incidents analyzed, and your API key with copy/reveal.
  • Added SDK snippets for C++, Python, and JS right inside the dashboard.
  • Improved New sidebar navigation shell shared across Overview, Incidents, Logs, Infrastructure, Profile, and Settings.
v0.3.0June 2026
  • Added Dedicated Sign Up and Log In pages, styled to match the landing page.
  • Added Email + password accounts with first and last name, backed by hashed passwords and per-user API keys.
  • Improved "Get Started" and "Start Free" now route straight to Sign Up; "Sign In" goes to Log In.
  • Fixed Existing accounts migrate safely to the new schema — no data loss for early users.
v0.2.0June 2026
  • Added Public documentation page covering setup, the analyze API, and SDK usage.
  • Improved Shared visual system applied consistently across marketing pages.
v0.1.0May 2026
  • Added Landing page introducing Roota's positioning: an AI debugger for high-concurrency systems.
  • Added Core CLI: debugai --log crash.log parses tracebacks and crash dumps and sends structured context to AI for diagnosis.
  • Added C++ crash dump support via addr2line, resolving raw memory addresses to source file and line.
  • Added GitHub repo integration so diagnoses reference your actual source, not just the log.
That's everything so far. Have a request or spot a bug? Reach out directly.
