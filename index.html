Python Auto-Capture

                

                    Add two lines to your Python app. Every unhandled exception gets automatically captured, analyzed, and stored.
                


                
1. Copy debugai_sdk.py into your project

                

                    
cp debugai_sdk.py /your/project/

                


                
2. Add to your app

                

                    
import debugai_sdk

debugai_sdk.install(
    repo="owner/your-repo",
    server="http://127.0.0.1:8000"
)

                    
                


                

                    

                        ✓ Works with any Python app — Django, Flask, FastAPI, scripts, services
                    

                

            


            

                
C++ Crash Handler

                

                    Header-only, binary-agnostic crash handler. Automatically captures crash address, memory map, and signal — no debugger required.
                


                
1. Copy header into your project

                

                    
cp cpp_integration/debugai_handler.h /your/project/

                


                
2. Add to your main.cpp

                

                    
#include "debugai_handler.h"

int main() {
    debugai::install_crash_handler("logs/");
    
    // ... rest of your code
}

                    
                


                
3. Compile with debug symbols

                

                    
g++ -g your_app.cpp -o your_app

                


                
4. Analyze the crash report

                

                    
python debugai.py --log service.log \
    --repo owner/repo \
    --crash-report logs/crash_report_*.log

                


                

                    

                        ✓ Header-only — no dependencies, no build system changes required
