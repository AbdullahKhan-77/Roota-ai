Frequently asked questions

Is the free plan really free forever? +
Yes. The Developer plan is free forever for individual use. We'll always maintain a free tier — it's how we build trust with engineers before asking for money.
When will paid plans launch? +
We're currently in beta. Paid plans (Team and Enterprise) are in development and will launch later in 2026. You'll be notified when they're ready if you sign up now.
Do I need to give Roota access to my codebase? +
For public GitHub repos, no — Roota fetches files directly from GitHub's public API without authentication. For private repos, you'll provide a GitHub token with read-only access. We never store your source code permanently.
What AI model does Roota use? +
Currently Roota uses Google Gemini for analysis. Multi-model support (Claude, GPT-4, and local LLMs for on-premise) is on the roadmap for Enterprise.
Can I self-host Roota? +
The core engine is open source and can be self-hosted today by cloning the repository. A packaged on-premise deployment option with support will be available in the Enterprise plan.
